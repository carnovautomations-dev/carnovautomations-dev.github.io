Lead follow-up system for installers

n8n, PostgreSQL, NocoDB, Telegram, JavaScript

Open-source v1 on GitHub

v2 tested end to end, ready to install
  • Replaces "whoever remembers to check the inbox" with a process that runs on its own.
  • Leads from the website, from trade-show stands and from voice notes recorded after a site visit, all in one place.
  • The team works from Telegram: a card per lead, buttons to update status and set reminders.
  • Self-hosted: PostgreSQL with nightly backups, a password-protected table view per client, secrets kept out of the workflows.
